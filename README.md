# Mortis Entertainment

El presente proyecto consiste en el desarrollo del sitio web de **Mortis Entertainment**, un proyecto experimental enfocado en el desarrollo y publicación de videojuegos.

El objetivo es crear progresivamente una identidad propia para la compañía, desarrollar diferentes proyectos relacionados con videojuegos y utilizar el sitio web como plataforma para presentar dichos proyectos.

## 🎮 Sobre el proyecto

**Mortis Entertainment** es un proyecto de largo plazo que busca experimentar con diferentes áreas del desarrollo de videojuegos y tecnologías web.

El sitio web funcionará como el espacio principal de la compañía para presentar sus proyectos, videojuegos, información y contenido relacionado.
